## 📖 项目背景

牛奶蛋白过敏（Cow's Milk Protein Allergy, CMPA）是婴幼儿最常见的食物过敏之一，约 2-3% 的婴儿受此影响。对于 CMPA 宝宝的家长来说，日常喂养最大的挑战就是：**不知道能吃什么、怎么做才安全**。

市售辅食中隐藏的乳制品配料繁多，家长们往往需要在无穷无尽的配料表中反复排查。本项目旨在收集、整理并分享经过验证的 CMPA 安全食谱，帮助敏宝家庭轻松制作营养丰富又安心的辅食。

## 🎯 项目目的

- 📚 收集经过家长验证的 CMPA 安全辅食食谱
- 📋 每道食谱标注食材清单、制作步骤、年龄适配和营养要点
- 🔍 明确标注食谱中的过敏原信息和替代方案
- 🤝 鼓励社区贡献，持续扩充食谱库

## 🍽️ 食谱分类

| 分类 | 年龄阶段 | 代表食谱 |
|------|---------|---------|
| 初添加（4-6月） | 泥糊状 | 大米米糊、南瓜泥、苹果泥 |
| 进阶期（6-8月） | 细颗粒/软烂 | 红薯泥、牛油果香蕉泥 |
| 咀嚼期（8-12月） | 碎末/小块 | 即将更新 |
| 幼儿期（12月+） | 家常软食 | 即将更新 |

## 🚀 使用说明

1. 浏览 `recipes/` 目录中的食谱
2. 查看每道食谱的**食材清单**和**制作步骤**
3. 注意查看**年龄适配**和**过敏原提示**
4. 根据宝宝的实际情况调整食材和用量
5. 首次尝试新食材时，建议单一食材引入并观察 3-5 天

## 🤝 贡献指南

欢迎所有敏宝家长和营养师贡献食谱！请参考 [CONTRIBUTING.md](CONTRIBUTING.md) 了解详细的贡献流程。

### 贡献格式要求

- 每道食谱使用 Markdown 格式
- 必须包含：食材清单、制作步骤、年龄适配、营养提示、过敏原提示
- 食谱名称使用英文 kebab-case 命名（如 `carrot-rice-puree.md`）

## ⚠️ 免责声明

本项目中的食谱仅供参考，不构成医疗建议。每个宝宝的过敏情况和耐受度不同，添加新食材前请咨询儿科医生或营养师。详见 [DISCLAIMER.md](DISCLAIMER.md)。
